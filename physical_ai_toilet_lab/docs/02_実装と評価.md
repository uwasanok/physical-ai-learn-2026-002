# 実装順と試行錯誤の計画

以下は計画であり、記載された成功率や接触性能を達成したという報告ではない。

**2026-10-24更新：接触の精密再現は後回し。最新の必須仕様は[04](04_複数回清掃モデル.md)。**
以下の力制御・力センサー・過大力評価は将来拡張の案として残すが、現在の完了条件には含めない。
当面は面との距離・向き・こすり移動量による簡易判定と、n回目の除去・残留確認を使う。
段階0に加え、段階2のうちロボットを含まない幾何モデルを先行実装した。

## 段階と完了条件

|段階|実装内容|次へ進む条件|
|---|---|---|
|0：幾何の確認|凹面・固定筐体・俯瞰カメラ・汚れの生成。法線を可視化|曲面上の点と法線が整合。実機寸法と区別して記録|
|1：見える・届くの確認|実寸を意識した便器形状、RGB-D、アーム、工具。可視性とIKを検証|評価対象領域を決定。死角と到達不能点を明示|
|2：接触の基準実験|汚れ位置を既知とし、曲面追従＋接触フィードバックを実装|非接触では汚れが減らず、接触時にこすると減る。過大力・衝突を検出|
|3：画像AIを接続|画像からの汚れマスク→3D目標→清掃→再観測|未学習の配置で、真値を使わず清掃できる。影や死角を誤判定しないか測定|
|4：模倣学習を比較|基準制御のお手本を記録し、局所的なこすり動作をBCで学習|同じ試行条件で基準制御と比較し、改善点と失敗点を説明できる|
|5：必要なら強化学習|清掃速度や往復幅など限定したパラメータを最適化|報酬の抜け道がなく、未学習条件で改善を確認|

まず段階3までを実用に沿った最小作品とする。講義の模倣学習を試す場合は段階4を加える。
VLAの大規模学習や、全動作をゼロから強化学習する構成は初手にしない。

## ソフトウェア構成案

ROS 2 Jazzy＋Gazebo Harmonicを継続利用し、関節制御はgz_ros2_controlを候補とする。
既存のStep 1イメージは予備計算だけに使用。本実装のDockerfileとコンテナは新規に分ける。
MoveItを使う場合、接近・退避・IK・非接触区間の経路計画を担当させる。
MoveItの導入だけで力制御が完成するわけではない。
清掃時のブラシと対象面の接触は意図した接触として扱い、それ以外のリンク衝突は監視を維持する。

```text
simulator     : 便器、アーム、カメラ、接触、仮想汚れの真値
perception    : RGBから汚れマスク。深度から3D位置と法線
planner       : 清掃領域、曲面上の往復軌道、接近・退避
controller    : IK、関節制御、法線方向の接触補正、異常停止
supervisor    : 観測→接近→清掃→退避→再観測の順序
evaluator     : 真値による残留量、力、時間、衝突、成功率の集計
```

RGBと深度の内部・外部校正、カメラ→筐体→アーム→工具の座標変換を定義する。
RGBと深度を無条件に同じ画素の対応とせず、位置合わせと時刻を検査する。
基準制御にのみ真値を使う「上限性能」の実験と、カメラ入力のみで目標を決める本実験を分ける。

## 画像AIの学習

小型のセグメンテーションモデルを合成RGB画像と汚れマスクで学習する案を第一候補とする。
学習用・調整用・最終評価用をシーンseed単位で分離。便器形状を変える試験は別条件として集計する。
初期モデルの規模はデータ量と誤認識を見て決め、最初から大きなVLMに依存しない。
RTX 4090を学習に使用する計画。物理シミュレーションまで自動的にGPU化されるわけではない。

## 模倣学習で何を学ばせるか

最初は高次元の全関節トルクではなく、清掃面の局所座標で「次にどちらへ、どれだけこするか」を学習する。
観測：汚れマスクの局所特徴、工具姿勢、関節状態、接触力。
行動：接線方向の微小移動と、制限内の法線方向補正。下位のIKと力の監視は維持する。
お手本は成功した基準制御の軌道から集める。学習は観測→行動の対応を近づけるBehavior Cloning（BC）。
スクリプトのお手本は人の熟練清掃データではないことを明記する。
損失が下がるだけでなく、清掃を最後まで実行した結果で評価する。

画像・深度・関節・力・行動に共通のシミュレーション時刻を記録する。
入力の欠損、古い画像、行動適用時刻のずれを検出する。収集と再生で行動周期を揃える。

## 比較実験（experiments.csvに対応）

1. 同じ汚れ配置で、固定ブラシ姿勢と曲面法線に合わせる姿勢を比較。
2. 同じ曲面で、位置制御のみと接触フィードバックを比較。
3. 汚れ真値、色しきい値、画像AIを比較し、認識誤差と制御誤差を分離。
4. 基準制御とBCを、同じ未学習seedと時間制限で比較。
5. 影、反射、深度欠損、縁の死角、工具による遮蔽を増やして限界を測定。

最初の動作確認は数例で行い、比較は共通の調整用10シーンで進める。
条件を凍結後、別の20シーンで最終評価する案。20例でも実用信頼性の証明には不足する。
最終評価での不具合を直したら、その20シーンは調整用へ移し、新しい評価seedを用意する。

## 記録する指標

- 真の汚れ残留率：表面の面積重み付き残留量／初期量。初期汚れゼロは別ケース。
- 認識性能：マスクIoU・見逃し率・誤検出率。真の残留率と混同しない。
- 接触追従：法線力の誤差、上限超過時間、接触喪失率、ブラシ姿勢誤差。
- 実行結果：清掃時間、到達不能点、工具以外の衝突、終了理由。
- 可視性：対象領域の観測率と未確認面積。死角があるのに全体完了を出す割合。

当初の開発目標案：観測・到達可能な対象領域の残留率10%以下、意図しない衝突0、
上限超過による中止0を同時に満たす。時間上限は接触試験後に決め、比較手法で共通にする。
数値は開発上の判定基準であり、現実の衛生・安全基準ではない。

## 必須の失敗ケース

空中で動く／触れたまま静止／接触力過大／工具が縁に当たる／画像が欠損／深度が欠損／
汚れゼロ／見えない汚れ／汚れが消えたように見える反射変化。
それぞれ正常終了・再観測・中止・未確認のどれにするかを、実装前に決める。
