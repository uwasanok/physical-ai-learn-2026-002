# 学習画像AIを清掃動作に接続した結果

2026-10-24、Step 1と別のラボで実行。新規の3配置で、毎回の画像推論から目標を決め、UR5eの実際の順運動学で得た先端位置・向きを簡易接触モデルへ入力した。
既存の清掃目標列を再生して検証したものではない。HTML・動画は、そのオンライン計算で記録した結果の再生である。

## 仕組みと講義の活用

1. 俯瞰カメラで撮影する。アームは撮影用の退避姿勢。
2. 学習済みU-NetがRGBだけから汚れ画素を予測する。
3. カメラの校正値・既知の便器形状から、汚れの3D座標と面の向きを求める。
4. 逆運動学で関節角度を計算する。全区間の経路を衝突検査してから実行する。
5. 曲面を短くこすり、退避して再撮影する。残っていれば繰り返す。

講義のタスク空間と関節空間、順運動学・逆運動学、観測と行動のフィードバック、認識と制御の分離を活用している。
関節角度は「どれだけ曲げるか」、トルクは「回す力」。今回の出力は関節角度であり、トルク出力の学習・実機の追従制御は実装していない。
画像認識だけを学習し、幾何・運動学をアルゴリズムで処理する構成でも、AIを使ったロボットタスクとなる。
配布課題PDFは「推論のみでも可、学習は任意」。全講義の手法を実装する要求ではない。合否の最終判断は講座側が行う。

## 条件と結果

学習・画像評価とは異なるseed 410001〜410004を使用。画像モデルとしきい値0.4は凍結したまま。
3箇所にn=1・3・5の汚れを配置し、配置・色・露出・色温度・固定画像ノイズを変更した。各撮影間で照明やノイズは固定。
画像は学習生成器そのものではなく、既存の区画描画に色と照明変化を加えたもの。カメラ・仮便器・ROIは同じ。

| 条件 | 清掃回数 | 終了時の残留区画 | 終了 |
|---|---:|---:|---|
| 新規配置410001 | 23 | 0 | 画像上クリア |
| 新規配置410002 | 20 | 0 | 画像上クリア |
| 新規配置410003 | 36 | 0 | 画像上クリア |
| 汚れなし | 0 | 0 | 動かず終了 |
| 配置410001・n=999・上限3回 | 3 | 166 | 未完了のまま上限停止 |

通常の試行上限は100回。nは各局所区画が受ける有効な通過回数であり、全体の動作回数とは異なる。
計95,984姿勢を計画中に検査。保存された全実行姿勢の再検査を含む40テストが56.493秒で成功。
同一配置でnだけ変更しても初回RGBと初回目標が同じことをテストし、必要回数が計画へ漏れていないことも確認。
最初の再検査では接近・退避をすべて移動扱いにしたテスト側の誤りがあり、接触許可条件を元のフェーズで再検査するよう修正した。衝突例外や本体の許容条件は変更していない。

結果：`output/closed_loop_v1/summary.json`、各条件の `motion.npz`・撮影画像・マスク・ログ。
3D表示：`output/closed_loop_v1/learned_cleaning_3d.html`（約3倍速の確認用。提出動画とは別）。
全HTML表示を実ブラウザで検証したものではなく、Canvas APIの実行チェックと別途静止画描画を実施した。

## 再実行

ラボ直下で次を実行。GPUを使えるDocker環境と既存の `physical-ai-toilet:training` イメージが必要。

```powershell
docker run --rm --gpus all --network none --mount "type=bind,source=$PWD,target=/work" physical-ai-toilet:training python3 learned_closed_loop.py
docker run --rm --gpus all --network none --mount "type=bind,source=$PWD,target=/work" physical-ai-toilet:training python3 -m unittest discover -v
docker run --rm --network none --mount "type=bind,source=$PWD,target=/work" physical-ai-toilet:training python3 make_submission_video.py
```

再実行は閉ループ結果フォルダを更新する。提出時の測定結果を保つなら展開コピーで実行する。
重みの再学習は不要。学習スクリプトは既存の凍結結果の上書きを拒否する。

## 今回の到達点と残る範囲

限定ROIで「見て・こすって・見直す」を画像AIと既製アーム寸法に接続したシミュレーション実証が完了した。
曲面・関節制限・離散姿勢での形状干渉は検査したが、剛体動力学・押付け力・モーター追従・トルク・除菌性能は未評価。
便器はメーカーCADではなく仮形状。実機で動かせる軌道であると保証しない。
